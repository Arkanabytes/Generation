## 📚 Progreso de Aprendizaje

### Conceptos Completados ✅
- **Sintaxis básica**: Variables, constantes, tipos de datos
- **Operadores**: Aritméticos, lógicos, relacionales, ternarios
- **Estructuras de control**: if/else, switch, bucles (while, for, do-while)
- **Fundamentos sólidos**: Base establecida para conceptos avanzados

### En Progreso 🔄
- **Métodos y funciones**: Parámetros, return, sobrecarga
- **Arrays**: Manejo básico y estructuras unidimensionales
- **Introducción a POO**: Conceptos básicos de clases y objetos

### Por Aprender ⏳
- **POO Avanzado**: Herencia, polimorfismo, encapsulación, abstracción
- **Manejo de excepciones**: Try-catch, throws, finally
- **Colecciones**: ArrayList, HashMap, LinkedList, etc.
- **Programación funcional**: Lambda expressions, streams
- **Multithreading**: Concurrencia y paralelismo

## ⚡ Inicio Rápido

### Prerrequisitos
- ☕ Java JDK 11 o superior
- 💻 IDE (IntelliJ IDEA recomendado)
- 📁 Git instalado

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/Arkanabytes/Generation.git

# Navegar al directorio
cd Generation

# Explorar la estructura
ls -la
```

### Compilar y Ejecutar
```bash
# Compilar un archivo Java
javac 01-fundamentos/operadores/Operadores.java

# Ejecutar el programa
java -cp 01-fundamentos/operadores Operadores

# O usar tu IDE preferido para ejecutar directamente
```

### Navegación Recomendada
1. 📖 Revisa la [documentación](docs/) para contexto
2. 🏃‍♂️ Comienza con `01-fundamentos/` si eres principiante
3. 📝 Consulta los comentarios dentro de cada archivo
4. 🎯 Sigue el orden numerado para una progresión lógica
